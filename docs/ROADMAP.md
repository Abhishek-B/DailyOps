# Roadmap

## Now
- Stable single-file local demo
- Refined DailyOps visual theme
- Multi-venue workflows
- Local sample data

## Backend MVP
- Supabase Auth
- Organisation / venue membership
- Persistent templates, rosters, daily lists and task history
- RLS policies
- Realtime completion updates

## Notifications
- Immediate manager alert when a list is fully complete
- Scheduled venue end-of-day report
- Email summary and optional CSV attachment

## Later
- CSV roster importer UI
- File/photo evidence on tasks
- organisation branding/logo upload
- audit trail
- analytics dashboard
- PWA/offline support if needed
